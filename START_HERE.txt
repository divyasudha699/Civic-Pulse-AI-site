CIVIC PULSE AI INDIA - FINAL UPGRADED VERSION

1. Extract the ZIP completely.
2. Open the Civic_Pulse_AI_India_Final folder.
3. Click File Explorer address bar, type: cmd
4. Run:
   py -m venv .venv
5. Run:
   .venv\Scripts\activate
6. Run:
   pip install -r requirements.txt
7. Run:
   streamlit run app.py
8. Open in browser:
   http://localhost:8501

DUPLICATE FEATURE
Same category + same/near place + similar description is merged into ONE incident.
The government sees the incident once, with an increased reporter count.

DATA
